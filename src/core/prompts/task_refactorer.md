1. **分階段 (Stepped)**：將任務拆解為邏輯相承的階段。
2. **社交邊界**：未獲得對方正面回饋前，嚴禁洩露後續階段細節（如預算、特定要求）。
3. **代理角色**：計畫必須指示 Hermes 「代表委託人」行動（例如：代表委託人詢問意願，而非問對方需不需要服務）。
4. **任務性質區分**：
